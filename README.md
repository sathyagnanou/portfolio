# Sathya Gnanou · Portfolio

Personal portfolio of Sathya Gnanou, Master's student in Data Science at Université Paris-Saclay, looking for a 6-month end-of-studies internship (Data Science, Machine Learning, Data Engineering, AI) from March 1st, 2027.

Live site: https://sathyagnanou.github.io/portfolio/

## What's inside

- One self-contained page: `index.html` (HTML, CSS and vanilla JavaScript, no build step).
- French and English, switchable with a button.
- Light and dark themes.
- Interactive figures: a tools → projects → themes map, benchmark charts from the inpainting detection report, a case explorer for the Fairness in AI project, a skills tracer and an education timeline.

## Run locally

Open `index.html` in a browser.

## Deploy with GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then **Save**.
4. After a minute the site is live at `https://sathyagnanou.github.io/portfolio/`.
